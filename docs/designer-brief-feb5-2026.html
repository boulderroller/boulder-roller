Conceptual UX Decisions

✓ Implemented

Major UX philosophy baked into the product (Jan 19):

ConceptWhat It Means
Anonymous names BitMEX-style pseudonyms from wallet hash. "Sovereign Covenant" not "0x3f8a..."
Anti-gamification Opacity over transparency. Users see position, not mechanics. No "you're 47 points from Tier 2!"
Privacy zones Strava-style GPS fuzzing. 5 zones per user, 200-1600m radius. Already wired.
Inline state machines Subtext status updates instead of modal spam. idle → input → confirm → processing → success

Discussion Points

1. Upload Progress Visualization High priority

User uploads a file. Backend does: parse → validate → project to tiles → detect climbs → match vaults → award points.

Current: Single spinner, then result.
Desired: Staged progress indicator. Each step visualized.

Question: Horizontal stepper? Vertical list? Animation style?

2. Vault Match Moment High priority

User uploads ride. We detect they crossed 3 known climbs. This is THE key moment.

Current: Text list of matched vaults.
Desired: Celebratory but not cheesy. "You completed Box Hill. Earned 47 points."

Question: Modal? Inline expansion? Card stack?

3. Points Balance Placement Medium

Users earn points. Where do they see this?

Options: Header (always visible), Dashboard hero stat, Profile only, Dedicated "Earnings" tab

Question: How prominent? Pre-token so don't overhype, but users need feedback loop.

4. Leaderboard Visual Design High priority

Now a rich component: rank, trend arrows, time, gap to next, attempt count, earnings.

Current: Functional table.
Desired: Feels competitive. Rank 1 should feel special.

Reference: Strava segment leaderboards, but with earnings column.

5. Settings Polish Pass Low priority

Tabs: Profile, Privacy, Connections, Sessions. Stable but boring.

Quick wins: Better section headers, input consistency, privacy zones map preview, connected accounts visual state.

6. Empty States Audit Medium

We added empty state copy in UX gap work. Need visual pass.

Key states: No rides yet, no vaults staked, no leaderboard positions, Strava not connected.
