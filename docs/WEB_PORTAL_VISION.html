PRODUCT VISION

Web Portal

A comprehensive web experience for managing your beetle, exploring piles, tracking performance, and participating in the economy.

0 Portal Philosophy

Web vs. Mobile: The web portal is for deep engagement — analytics, portfolio management, map exploration, governance. Mobile is for quick actions — recording rides, checking stats, uploading.
📊
Data-Rich Experience

TrainingPeaks-level analytics and visualization. Power curves, TSS trends, performance charts.

🗺️
Full Map Exploration

Discover piles globally. Filter by tier, activity, potential yield. Plan routes.

💰
Portfolio Management

Track your claims, LP positions, earnings history. Stake/unstake with full context.

⚖️
Governance Hub

Swanny seat management, tribunal voting, photo curation. Community-first moderation.

Design Principles

  • Utilitarian elegance — Professional, clean, no unnecessary decoration
  • Data density — Show more information, let power users thrive
  • Keyboard-first — Power users can navigate without mouse
  • Dark mode native — Default dark, light optional
  • Progressive disclosure — Simple surface, depth on demand

Key UX Flows

1. New User Onboarding

Landing Page
    ↓ Click "Get Started"
Connect Wallet (Phantom/Solflare)
    ↓ Sign message
Create Beetle (auto-assigned #)
    ↓ Shown empty card
Dashboard (empty state)
    ↓ CTA: "Upload your first ride"
Upload Ride Flow
    ↓ GPX/FIT processed
First DUNG earned! 🎉
    ↓ Guided tour of dashboard
Suggest nearby piles to stake in

2. Stake in Pile

Map Explorer or Pile Detail
    ↓ Click "Stake DUNG"
Staking Modal:
  - Amount input
  - Show projected weekly yield
  - Show current APY
  - Show your new share %
    ↓ Confirm
Sign Transaction (wallet)
    ↓ Success
Updated stake shown in Portfolio

3. Claim Swanny Seat

Pile Detail → Open Swanny Seat
    ↓ Click "Claim Seat"
Swanny Modal:
  - Confirm 1,000 DUNG lock
  - Show 30-day commitment
  - Show expected earnings
  - Show required tasks
    ↓ Confirm
Sign Transaction
    ↓ Success
Swanny badge on profile
Governance tab unlocked

4. Weekly Epoch Distribution

Sunday 00:00 UTC
    ↓ Backend triggers close_epoch()
Notification: "Epoch 47 complete!"
    ↓ User visits Dashboard
"Claim Rewards" button active
    ↓ Click claim
Sign harvest_rewards() tx
    ↓ Success
Boulder updated
Transaction in history

Technical Considerations

Frontend Stack

  • Framework: Next.js 14 (App Router)
  • Styling: Tailwind CSS + custom design tokens
  • State: Zustand or Jotai (simple, performant)
  • Web3: @solana/web3.js + wallet-adapter
  • Maps: Mapbox GL JS
  • Charts: Recharts or Tremor
  • Data fetching: TanStack Query

Real-Time Features

  • WebSocket for live leaderboard updates
  • SSE for epoch countdown sync
  • Polling fallback for wallet balance

Performance Targets

  • LCP < 2.5s (Largest Contentful Paint)
  • FID < 100ms (First Input Delay)
  • CLS < 0.1 (Cumulative Layout Shift)
  • Map load < 1s with cached tiles

Accessibility

  • WCAG 2.1 AA compliance
  • Full keyboard navigation
  • Screen reader support
  • Color contrast ratios met
