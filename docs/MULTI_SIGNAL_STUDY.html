06 Button System

Multi-Signal Design System

Semantic Color

Each color maps to a data domain. Mint = fitness/performance. Violet = economy/tokens. Coral = actions/energy. Amber = time/urgency. Users learn the system unconsciously — glancing at the screen tells them what type of information they're looking at.

Gradient as Signature

The mint→violet→coral gradient becomes the brand signature. Used on borders, buttons, text highlights, and the beetle identity. It's immediately recognizable and ties the multi-color system together into a cohesive visual language.

Ambient Atmosphere

Floating color orbs in the background create depth without distraction. They drift slowly, suggesting life and energy. The interface feels alive without being busy. This is borrowed from modern social apps but applied subtly.

Higher Contrast

Text legibility improved from the 2027 study. Primary text at 92% opacity, secondary at 75%, tertiary at 55%. Labels at 35%. All pass WCAG AA. The void base makes every color pop without competing.

Terminal Integration

The terminal uses different prompt symbols and colors for different data types. Fitness data gets mint (◆), economic data gets violet (◇), action states get coral (●), system messages get cyan (→). Power users can scan the log by color.

Identity Card

The beetle card uses the gradient border and gradient text to tie together the multi-color system. Stats are color-coded by domain. The boulder pulses with the violet→coral gradient. It's unmistakably yours.
