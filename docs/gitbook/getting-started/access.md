# Access

Boulder Roller is invite-only.

If you have a code, open
[app.boulderroller.xyz](https://app.boulderroller.xyz) and choose **Enter
invite code**, or tap **Have an invite code?** on the first iOS screen, and
create your account. The code is used up at account creation; you will not
need it again.

Without a code, choose **Enter invite code**, then **Request access**, enter
your email address, and choose **Request invite**. The iOS app has no request
form. Boulder Roller sends invitations by hand as places open.
