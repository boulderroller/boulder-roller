# Fees and minimums

| Action | Fee or minimum |
|--------|----------------|
| Create a vault | 100 DUNG, burned. The alternative, 1,000 CAL burned plus 2 devnet test USDC, is not open yet |
| Deposit CAL | 100 CAL minimum; no fee |
| Withdraw CAL | 0.5% exit fee, burned; withdrawals are not open yet |
| Collect DUNG earned by a deposit | 5%, paid to the protocol treasury |
| Leaderboard and Local Legend DUNG | None; paid at settlement |
| Uploading, recording, results | None |

There is no subscription and no charge for access. Boulder Roller pays the
Solana network fee on every transaction.
