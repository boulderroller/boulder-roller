Design Language Summary

  • Palette: Carbon blacks + burnt ember orange. Warm cream text, not cold white. Industrial, not crypto.
  • Typography: IBM Plex Mono for data/terminal. Space Grotesk for UI. Tight letter-spacing on labels.
  • Terminal: Real timestamps. Live status dots. Pending/confirmed states. Cursor blink. Makes it feel alive.
  • Instruments: Top-bar accent stripe. Sparklines in every metric. Data should have shape, not just numbers.
  • Hierarchy: 10px uppercase labels → large mono values → small unit text. Consistent everywhere.
  • Motion: Subtle pulse on live indicators. Rolling animation on boulder. Hover states on everything.
  • The Boulder: Glowing ember orb. Appears in beetle card, loading states, achievements. Your signature.
