# Boulder Roller Design Docs

Start here before changing product language, portal layout, mobile hierarchy, or
visual direction:

- `BR_IDENTITY_SYSTEM.md` - canonical identity contract.
- `PORTAL_DESIGN_SYSTEM_2026.md` - active public-root-to-portal visual contract.
- `LANGUAGE_SPEC.md` - rider-facing copy and visibility rules.
- `PROOF_ECONOMY_PRIMITIVES.md` - rider-experience grammar for rides, climbs, CAL, DUNG, positions, and receipts.
- `PRODUCT_PATH_REGISTRY.md` - product path map across app surfaces.
- `BR_PRIMITIVE_TARGETS_2026-05-12.md` - primitive targets tied to the identity system.
- `renderings/README.md` - current visual boards and captures.
- `../PORTAL_TRUTHS.md`, `../MOBILE_TRUTHS.md`, and `../PROTOCOL_TRUTHS.md` - semantic truth hierarchy.

Do not treat copied prototype bundles, old audits, or generated design exports as
current direction unless a current source-of-truth document links to them
explicitly. Historical material can be useful for archaeology, but active work
must follow the identity system and language spec first.

The copied prototype bundles `Portalalpha-main/` and `Boulderrollercopy-main/`
were removed on 2026-11-05. Restore one with
`git checkout b22288b8e -- docs/design/<folder>`.
