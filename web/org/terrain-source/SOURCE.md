# Wises homepage relief source

Self-contained source for selected B, Blender4.3.2/Cycles. No saved scene or private workspace dependency is needed.

Run from this directory (use your installed Blender executable):

```
blender --background --factory-startup --python-exit-code 1 --python render_wises.py -- --output-dir generated
```

The command explicitly creates generated/hc-final.blend, generated/hc-final.png (3080×2170 RGBA,64 samples), and generated/hc-final-output-provenance.json. Source files are never rewritten. The script verifies all bundled hashes, the236 recorded GPS plan coordinates, and exact selected-final geometry/control-point, curve-width, route/endpoints/material, camera, light/world, all-material and ray-visibility fingerprints before rendering. A mismatch stops the build; no guard is weakened.

The tiny endpoint-mesh gzip preserves the exact selected glyph topology, including deterministic edge order. It does not provide landscape or GPS truth.

The687,008-byte NPZ is the unchanged native USGS crop. The gzip contains the original contour/DEM-draped-road JSON byte-for-byte after decompression. wises-recorded-gps.json contains the actual236 retained historical GPS samples. Coordinates, native heights,2m contour levels, original1× relief, camera, seeded v2 ink/color grain, and selected B lighting/material treatment are preserved. Grain is color only; mesh normals are smooth but vertices are unsmoothed. Small original stroke offsets are cosmetic annotations; the recorded ride altitude is not used as landscape elevation.

source-provenance.json records native source, geographic frame, historical interval, seed, hashes and expected guards. Keep only these source files in the repository; generated/ and _validation/ are render outputs, excluded by the local ignore file. Do not ship the Blender scene or source grid to the browser.
